# Excel Reports

Открывать при печатных формах, регламентированных отчетах, счетах, актах, накладных и отчетах по `.xlsx`-макету.

## Источники

- `basys-docs/ru/reporting/excelReport.md`.
- Паттерны: `reference/INDEX-excel_report.md`.

## Правила

- Для обычных интерактивных таблиц использовать `data_view`, не Excel-отчет.
- Excel-отчет выбирать, когда нужен макет, печатная форма или регламентированный формат.
- Макет `.xlsx` должен быть частью поставки, если отчет зависит от него.
- Данные для отчета должны иметь ясный контракт колонок.

## Чек-лист

- В ТЗ указано, зачем нужен именно Excel-отчет.
- Источник данных и параметры отчета описаны.
- Все связанные файлы включены в инструкцию импорта/поставки.
