# Menu

Открывать при изменении навигации, групп, ссылок на справочники/операции/отчеты и объекта `menu`.

## Источники

- `basys-docs/ru/metadata/menu.md`.
- Паттерны: `reference/INDEX-menu.md`.

## Правила

- Меню - навигационный объект, а не источник правды по существованию метаобъектов.
- Не добавлять пункты меню сверх ТЗ.
- Осторожно с `AutoFill`: он может дублировать ручные пункты.
- Для ссылок на новые объекты учитывать порядок импорта по ADR-003.

## Чек-лист

- Пункт меню имеет понятный `Title`.
- Ссылка ведет на существующий или создаваемый в этой партии объект.
- Группа не создает дублей с авто-заполнением.
- Изменения меню отражены в инструкции импорта.
