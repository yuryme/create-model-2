# Records Creation

Открывать при проведении операций по регистрам: `RecordsSettings`, `RecordsSources`, источники записей, направления Plus/Minus.

## Источники

- Документация: `basys-docs/ru/metadata/recordsCreation.md`.
- Паттерны: `reference/INDEX-records.md`, `reference/INDEX-operation.md`.
- UID: только `project/metadata/system/`.

## Правила

- Регистр вида `records` описывает измерения и ресурсы движений.
- Операция-источник содержит настройки проведения и источники записей.
- Источник записей может брать данные из шапки, табличной части или `.bjs` RecordsSource.
- Направление движения фиксировать явно: приход/расход, Plus/Minus, знак количества или ресурса.
- Для сложного расчета ресурсов создавать `.bjs` рядом с операцией и ссылаться на него из JSON.

## Чек-лист

- Регистр создан до операции, которая пишет в него, или импорт разбит на партии.
- Все `DataTypeUid` измерений и ресурсов взяты из собственного `dataTypes.json`.
- Проведение не полагается на UID из reference.
- Для каждой операции с проведением есть инструкция импорта.
