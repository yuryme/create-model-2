# Inbox — входящие материалы на разбор

Сюда пользователь складывает внешние файлы, которые нужно **изучить и обсудить** с AI-ассистентом: PDF, Excel, документы Word, скриншоты, выгрузки JSON/XML, презентации, ТЗ от заказчика и т.п.

## Принцип

- **Inbox — это рабочая зона, не архив.** После того как файл изучили и решили, что с ним делать, он уходит из inbox: либо переезжает в `reference/`, `project/docs/` или другое целевое место, либо удаляется.
- AI-ассистент **читает файлы только по явной просьбе** — содержимое inbox не загружается автоматически в каждую сессию.
- Имена файлов — желательно осмысленные (`tz-warehouse-2026-05.pdf` лучше, чем `документ1.pdf`), но строгой схемы нет.

## Что НЕ класть в inbox

- ⛔ Готовые метаданные BaSYS — это в `reference/metadata/`.
- ⛔ Финальные документы проекта — это в `project/docs/`.
- ⛔ Конфиденциальные ключи, пароли, API-токены.
