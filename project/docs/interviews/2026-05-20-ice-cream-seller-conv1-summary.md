## 2. Бизнес-задача (рабочая гипотеза)

Клиент — CEO розничного бизнеса по продаже мороженого (опт + розница + доставка домой) — хочет автоматизацию, при которой выполняются три условия:

1. Все данные бизнеса собраны в одном приложении (сейчас разбросаны по нескольким источникам — Excel у отдела продаж, бухгалтерия, клиент-банк, отдельный участок закупок).
2. Ключевые показатели руководителя «перед глазами» в любой момент (сейчас сбор данных еженедельно занимает целый день, бумажная выписка из клиент-банка по запросу — час).
3. От любого показателя можно «провалиться» до первичного документа.

Это рабочая гипотеза — клиент явно обозначил формулировку как первый набросок, не задачу. К финалу серии бесед будет уточнено, что именно за «ключевые показатели» и какие конкретно «первичные документы».

Дополнительная (сопутствующая) цель серии бесед — самим клиентом обозначенная — «новые знания об учёте». Клиент пришёл частично за знаниями о предмете, не только за решением.

## 3. Боли клиента

Семь болей, зафиксированных и подтверждённых клиентом в резюме после Тем:

1. **Сбор данных о продажах хрупкий.** Источник — файл Excel у отдела продаж. Раз в неделю «съезжают» строки таблицы. Для починки нужен директор по продажам, но он не всегда на месте. Последний случай — 2 часа ожидания исправления.

2. **Сбор данных о затратах разрознен на три источника.** Бухгалтерия (аренда, коммуналка), закупки, отдел продаж. На сведение картины уходит целый день; потребность — еженедельно.

3. **Поступления денег не доступны под рукой.** Бухгалтерия распечатывает бумажную выписку из клиент-банка по запросу. Последний случай — час на получение выписки за неделю. Потребность — ежедневно.

4. **Регулярные упущенные предложения новинок клиентам.** Около 10 клиентов в неделю забывают предложить новинки. Недополученная выручка — десятки тысяч ₽, накапливается ежемесячно.

5. **Критический инцидент — незаказанная фура с мороженым.** Разовый случай; миллионы ₽ недополученной выручки + имиджевые потери. Источник упоминания — отдел закупок, но за корнем стоит цепочка «отдел продаж → отдел закупок».

6. **Прайс-листы пересчитываются вручную тремя сотрудниками.** Три FTE заняты только пересчётом цен. Цены меняются раз в три дня. Триггеры волатильности — курс валют, погода на улице, цены конкурентов (динамическое ценообразование).

7. **Аналитика продаж по регионам России не делается.** Без неё хуже управление остатками на складах. Прямая связь с инцидентом № 5.

**Качественные характеристики набора:** боли описаны не как декларации, а как конкретные истории с цифрами и последствиями (применён принцип П9). Один пункт — критический одиночный инцидент (№ 5), остальные — регулярные операционные боли с измеримой частотой.

## 4. Процесс as-is

Тема T3 не входила в состав беседы. Раздел не заполняется в этом summary.

Косвенные фрагменты процесса, всплывшие в T2 и в ядре M1/M2 (для контекста, не как полноценная картина):

- Сбор данных о продажах: CEO → запрос директору по продажам → файл Excel в отделе продаж.
- Сбор данных о затратах: CEO → бухгалтерия + закупки + отдел продаж → сведение вручную (день работы).
- Получение выписки по приходу денег: CEO → запрос в бухгалтерию → бумажная распечатка из клиент-банка (час).
- Закупка товара: отдел продаж формирует месячный план с понедельными уточнениями → отдел закупок → поставщик.
- Прайс-листы для продаж: 3 сотрудника пересчитывают цены каждые 3 дня по триггерам (курс/погода/конкуренты).

Полная инвентаризация — задача следующих бесед.

## 9. Открытые вопросы к клиенту

### По модулям, не пройденным в этой беседе

**M3 Склад:**

- Сколько складов или площадок хранения — один центральный, несколько по регионам, при точках продаж?
- Сколько SKU мороженого в ассортименте?
- Как сейчас проводится инвентаризация? Как часто?
- Метод стоимостной оценки остатков — средневзвешенная, FIFO, по партиям?
- Какие документы оформляются при движениях склада — приходная накладная, расходная, акт списания, акт перемещения?
- **Поднятый клиентом на закрытии:** учёт хранения с аналитикой по срокам годности — как организован сейчас, что хотелось бы видеть?

**M4 Финансы и ДС:** все вопросы ядра — счета и кассы, регулярные платежи, прогноз поступлений, статьи ДДС, кассовые разрывы. Дополнительно — граница управленческого учёта денег и регламентированного бухучёта.

**M5 Аналитика:** все вопросы ядра — ежедневные показатели, имеющиеся отчёты, желаемые отчёты, период анализа, алерты. Дополнительно — конкретизация формулировки «ключевые показатели перед глазами» из T1.

**M6 Расчёты с контрагентами:** все вопросы ядра — виды взаиморасчётов, авансы, долги, сверка, валюта. Конкретно — условия расчётов с B2B-клиентами опта.

### Уточнения по уже пройденным модулям

- **M1:** что именно даёт тысячи сделок/день в рознице — сеть собственных точек, киоски при ТЦ, фуд-корты, что-то ещё? Это влияет на будущий складской учёт (M3).
- **M2:** при отсрочке 3 месяца и зафиксированных закупочных ценах — каким образом курс валют влияет на наши розничные прайс-листы (один из трёх триггеров пересчёта)? Гипотеза — через цены конкурентов, которые завозят импорт. Уточнить.

### Кандидаты на привлечение специалистов клиента к следующим беседам

CEO — единственное контактное лицо; часть деталей по областям, не закрытым в этой беседе, глубже знают исполнители. Кандидаты:

- **Директор по продажам** — углубление M1 (воронка, скидки, возвраты, кто формирует документы), процесс as-is для T3.
- **Главный бухгалтер / финансовый специалист** — M4 (счета, статьи ДДС, регулярные платежи), M6 (расчёты с контрагентами).
- **Складской мастер / менеджер склада** — M3 (инвентаризация, сроки годности, движения, оценка остатков).
- **Руководитель отдела закупок** — углубление M2 (процесс заявок от отдела продаж, фактический контроль исполнения — корень инцидента № 5).

## Предварительная оценка

- **Следующая беседа нужна.** Договорённость: через неделю (ориентировочно 2026-05-27), то же время. Ориентировочный состав — M3 + M4 + M5 + M6 с ядром. Это 4 модуля × ~5 вопросов = ~20 вопросов; по П12 — состав плотный. На подготовке PM-Аналитик решает: проходить все четыре модуля в одной беседе, или разделить на две (например, M3 + M4 = «деньги и склад»; M5 + M6 = «аналитика и расчёты»). Решение зависит также от того, кто будет на следующей беседе со стороны клиента (если придёт ещё кто-то из специалистов, можно охватить больше).

- **Привлечение специалистов** — рекомендуется. CEO даёт уверенные ответы по верхнему слою каждой темы, но детали (например, метод оценки остатков, статьи ДДС) лучше задавать соответствующим исполнителям. Это снизит риск ситуаций «не знаю, надо у Х спросить» в ходе следующей беседы.

- **Критерии двухэтапного цикла Аналитика** — преждевременно. Серия бесед не завершена; формулировка задачи существует только как рабочая гипотеза (раздел 2). Применять критерии (≥3 метаобъекта, новый вид конструкции, новый бизнес-процесс, ожидаемое ТЗ ≥400 строк) к итогу серии будет уже после её завершения.

- **Срок отдачи итоговой формулировки задачи** — после завершения серии, ориентировочно 2-4 беседы.

- **Уроки прогона** — оставлены для PM в отдельном сообщении, не в этом summary (методологическая обратная связь по самой методике, не часть содержания беседы).
