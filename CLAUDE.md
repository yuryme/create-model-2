# BaSYS-AI workspace

**В начале каждой сессии прочитать:**
- `Claude_Context.md` — текущее состояние проекта (где мы, что сделано, что дальше).
- `OPEN_QUESTIONS.md` — открытые вопросы и принятые решения.

Без этих двух файлов любые рекомендации по проекту будут с устаревшей картиной.

## Роли работы

В этом workspace работают две роли в разных чатах:
- **`/analyst`** — Аналитик (проектирование ТЗ в `project/docs/specs/`).
- **`/engineer`** — Инженер (разработчик + администратор, реализация ТЗ + инфраструктура).

PM — пользователь, координирует роли и утверждает ТЗ/реализации. Подробности — в `.claude/skills/<роль>/SKILL.md`.

## Конвенция о путях

Claude Code запускается **в корне workspace** (`create-model-1/`). Все пути в скиллах и в этом файле — относительно CWD = workspace root. Исключение: `$schema`-пути внутри JSON-файлов метаданных — относительные к самому JSON.

## Структура workspace

- `project/` — Git-репозиторий проекта (метаданные, скиллы, ТЗ, ADR).
- `basys-docs/` — клон официальной документации BaSYS (read-only). Карта — `basys-docs-index.md`.
- `reference/` — чужая выгрузка как банк паттернов (read-only). Карты — `reference/INDEX.md` + `INDEX-<kind>.md`.
- `inbox/` — входящие материалы на разбор.
- `Claude_Context.md`, `OPEN_QUESTIONS.md`, `project-setup-guide.md` — рабочие документы workspace.
